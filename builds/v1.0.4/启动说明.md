# 任务消息提醒应用 v1.0.3

## 更新说明
- 修复了窗口快捷键切换功能
- 优化了用户体验

## 运行方式
直接双击 `tasks_message.exe` 即可运行程序

## 系统要求
- Windows 7/8/10/11
- 需要安装 .NET Framework 4.5 或更高版本

## 注意事项
- 首次运行时，程序会在后台托盘运行
- 使用 Alt+Ctrl+T 快捷键可以切换窗口的显示和隐藏
- 使用 Alt+Q 可以快速退出程序

## 常见问题
- 如果程序无法启动，请确保系统满足要求
- 如果快捷键不生效，请检查是否与其他程序冲突
- 如果数据丢失，程序会自动从备份恢复
