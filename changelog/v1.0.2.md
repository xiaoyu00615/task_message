# v1.0.2版本更新内容
    - v1.0.2-0.1
        - 修复了当重新打开程序，完成时间被修改。
    - v1.0.2-0.2
        - 新增任务导出功能
            - 支持导出所有任务（包括已完成和未完成）
            - 导出格式为CSV，包含任务ID、名称、描述、状态、创建时间、完成时间、截止时间
        - 新增任务导入功能
            - 支持从CSV文件导入任务
            - 导入时会检查任务ID是否已存在，避免重复导入
        - 新增备份功能
            - 支持定时备份任务数据
            - 备份文件默认存储在`backups`目录下
            - 备份文件名格式为`backup_YYYYMMDD_HHMMSS.csv` 和 `backup_YYYYMMDD_HHMMSS.json`
            - 备份文件包含所有任务数据，包括已完成和未完成任务
    - v1.0.2-0.3    
        - 修复了自动备份弹窗
        - 修复了自动备份弹窗在程序启动时显示的问题
    - v1.0.2-0.4
        - 新增菜单栏
            - 新增“文件”菜单，包含导出、导入、备份、退出选项
            - 新增“设置”菜单，包含基本设置、备份设置、界面设置、通知设置、数据更新设置选项
        - 基本功能内容等信息
        - 备份与恢复功能
            - 自动备份 
                - 支持定时备份任务数据（bug-fixed）
                - 备份文件默认存储在`backups`目录下
                - 备份文件名格式为`backup_YYYYMMDD_HHMMSS.csv` 和 `backup_YYYYMMDD_HHMMSS.json`
            - 手动备份
                - 支持用户手动触发备份操作
                - 备份文件默认存储在`backups`目录下
                - 备份文件名格式为`backup_YYYYMMDD_HHMMSS.csv` 和 `backup_YYYYMMDD_HHMMSS.json`
            - 数据恢复（bug-error）
                - 支持从备份文件中恢复任务数据
                - 恢复时会检查备份文件是否存在，避免恢复不存在的备份
        - 外观设置
            - 窗口大小设置
                - 支持用户自定义窗口大小   
            - 新增界面主题设置（未完成）
                - 支持默认主题、浅色主题、深色主题
        - 通知设置
            - 支持任务完成通知
            - 支持任务过期通知
            - 通知测试
                - 支持用户测试通知功能，检查是否能正常收到通知
        - 数据更新设置
            - 更新频率设置（bug-fixed）
                - 支持用户自定义数据更新频率
            - 数据优化（未完成）
                - 支持用户测试数据更新功能，检查是否能正常更新数据
        - 搜索功能（bug-fixed）
            - 支持用户搜索任务
            - 搜索结果会实时显示在任务列表中
    - v1.0.2-0.5
        - 修复了设置自动备份设置间隔时间不保存的问题
        - 优化了菜单栏布局，合并了备份功能到设置中
    - v1.0.2-0.6
        - 新增快捷键设置
            - ALT + Q 强制退出程序
            - ALT + CTRL + T 切换任务列表显示模式
        - 修复了数据更新不生效的问题
    - v1.0.2-0.7
        - 优化了设置的布局 
    - v1.0.2-0.8
        - 优化了深色模式下的显示
            - 新增深色主题设置
            - 优化了深色主题下的任务列表样式
            - 优化了深色主题下的设置窗口样式
